# PyShop artwork archive

These are the original artwork studies, preserved without alteration. The selected identity is the layered aperture in direction 02. It remains the source for the current product artwork.

| Original | Role |
|---|---|
| [Coastal cabin composition](direction-01-demo-coastal-photo.png) | Sample artwork used to demonstrate the editor. This is a constructed composition, not a documentary photograph. |
| [Selected layered aperture](direction-02-selected-layered-aperture.png) | Selected logo. An identical copy is saved as the [selected master](../pyshop-selected-master.png). |
| [Light layered aperture](direction-03-layered-aperture-light.png) | Alternate concept only. Its checkerboard is baked into an opaque image, so it must not be used as a transparent logo. |
| [Diamond aperture](direction-04-layered-aperture-diamond.png) | Alternate concept, not the current product identity. |
| [Compact app icon](direction-05-layered-aperture-app-icon.png) | Optical-size source for smaller app icons, also preserved as the [small master](../pyshop-icon-small-master.png). |

The [selection record](selection.json) identifies the chosen direction. Production PNGs and the Windows icon are outside this archive. Keep the original studies here when rebuilding delivery sizes.
